# 밤팔이 사진관 디자인 시스템

이 사이트는 **한 사람의 동네 사진관**이다. 첫 화면은 사진관 진열장, 시대는 현상소 사진 봉투, 사건은 건조 줄에 집게로 걸린 인화 사진이다.
스크롤로 시대를 지나가면 촬영용 배경지(backdrop) 색이 바뀐다.
구조(레이아웃, 간격, 사진 모양)는 모든 시대가 공유하고, **시대마다 바뀌는 것은 테마 토큰(배경지 색 4개 + 제목 글꼴)뿐**이다.

## 미적 방향

- **기억에 남는 한 가지는 사진 자체**: 흰 인화지 테두리, 3:2 사진, 오른쪽 아래 주황 7세그먼트 날짜 각인(`07  3  2`). 다른 요소는 조용하게 둔다.
- 사진관 재료로만 말한다: 배경지(페이지 배경), 인화지(`--paper`), 크라프트 봉투와 파란 인쇄 양식(`--envelope`, `--envelope-ink`), 건조 줄과 검은 집게, 종이 연도 꼬리표, 나무 액자.
- 사진은 조금씩 기울어져 있다(`tiltOf(no)`, ±1.5°). 마우스를 올리거나 포커스하면 똑바로 선다. 이것 말고 카드 hover 효과를 더하지 않는다.
- 움직임은 첫 화면 진열장 사진이 현상되듯 떠오르는 한 번뿐이다(`@keyframes develop`). 섹션마다 등장 애니메이션을 넣지 않는다.
- 문구는 사진관 말투로, 쉬운 말로: "사진 20장", "앨범으로 돌아가기", "이전 사진", "다음 사진을 인화중입니다."
- 피할 것: 크림 배경 + 명조 + 테라코타, 검정 배경 + 형광 포인트, 가는 선의 신문 레이아웃, 대문자 모노 라벨, 가운뎃점(·)으로 잇는 메타 문자열, 모든 카드에 같은 둥근 모서리와 회색 그림자, 장식용 그라데이션.

## 토큰

### 시대 테마 토큰 (배경지, 시대마다 다름)

| 토큰 | 용도 | 규칙 |
| --- | --- | --- |
| `--bg` | 배경지 색. 페이지 배경과 빈 사진 속 배경 | 실제 사진관 배경지 색에서 고른다 (증명사진 하늘색, 졸업사진 갈색, 프로필 차콜 등). 흰 글자가 올라가므로 중간~어두운 명도 |
| `--fg` | 배경지 위 글자 (간판, 연도 이후 문구) | `--bg` 대비 4.5:1 이상 |
| `--muted` | 배경지 위 보조 글자 | `--bg` 대비 4.5:1 이상 |
| `--accent` | 진행 바, 포커스 링, 간판의 "밤팔이" | `--bg` 대비 4.5:1 이상 |
| `--font-display` | 제목 글꼴 (봉투의 손글씨 칸, 사진 제목) | `theme.font`: `sign`(Do Hyeon), `serif`(Gowun Batang), `hand`(Gaegu) |

- 네 색은 `#rrggbb` 6자리 hex. 스키마가 다른 형식을 거부한다.
- 배경지 위 글자 색만 시대를 따른다. 인화지·봉투 위 글자는 고정 토큰(`--ink`, `--ink-soft`, `--envelope-ink`)을 쓴다.
- 파생 색은 `color-mix()`로 만든다: 배경지 조명 bg+white 14%, 가장자리 그늘 bg+black 30%, 건조 줄 fg 55%, 액자·태그 테두리 ink 25%.

### 고정 재료 토큰 (`:root`)

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `--paper` | `#fbfaf5` | 인화지 |
| `--ink` / `--ink-soft` | `#22201c` / `#5e5a52` | 인화지·봉투 위 글자 |
| `--envelope` / `--envelope-ink` | `#e6d6b5` / `#24508f` | 크라프트 봉투, 파란 인쇄 양식 |
| `--stamp` | `#ff9a2e` | 날짜 각인 (빛 번짐 `text-shadow` 포함) |
| `--clip` | `#2b2b2b` | 건조 집게 |

- 글꼴: `--font-body`(Gowun Dodum, 본문), `--font-sign`(Do Hyeon, 간판·제목), `--font-serif`, `--font-hand`, `--font-stamp`(DSEG7 Classic, 날짜 각인 전용).
- 간격: `--space-1`(4) `-2`(8) `-3`(12) `-4`(16) `-6`(24) `-8`(32) `-12`(48) `-16`(64) `-24`(96).
- 본문 16px / 줄간격 1.75, 캡션 13–14px, 사진 제목 18/22/27px(중요도 1/2/3), 간판 "사진관" `clamp(96px, 30vw, 220px)`.

## 시대 테마 추가·수정 절차

1. `src/content/eras/<id>.md`를 만든다. 파일 이름이 시대 id이고, 사건의 `era:` 값과 같아야 한다.
   ```yaml
   ---
   title: 군 복무
   subtitle: 짧은 머리와 긴 하루
   start: 2021
   end: 2022
   theme:
     bg: "#4a5440"   # 올리브 배경지
     fg: "#f3f1e6"
     accent: "#e6d38a"
     muted: "#d3d6c4"
     font: sign
   ---

   봉투 메모 칸에 들어갈 소개 글.
   ```
2. 바로 옆 시대와 배경지가 확실히 달라야 전환이 보인다 (색상이나 명도 중 하나는 크게).
3. `npm run check:contrast`로 4.5:1 이상인지 확인한다. 배경지 가운데 조명 부분은 조금 밝아지므로 여유 있게 잡는다.

## 레이아웃 규칙

### 세로 모드 (기본, 모바일, JS 없음)
- 봉투가 위에, 그 아래 왼쪽 세로 건조 줄에 사진이 한 장씩 걸린다. 집게가 사진 왼쪽 위를 문다.
- 폭 720px 중앙 정렬, 좌우 16px 여백. 375px 폭에서 가로 스크롤이 생기면 안 된다.

### 가로 모드 (`html.is-horizontal`)
- 조건: `(min-width: 900px) and (min-height: 640px) and (prefers-reduced-motion: no-preference)`.
  이 쿼리는 `src/scripts/timeline.ts`의 `HORIZONTAL_QUERY`와 `src/pages/index.astro` head의 인라인 스크립트, **두 곳에 있으며 항상 같아야 한다.**
- 건조 줄은 화면 세로 가운데. 각 시대 안에서 홀수 번째 사진은 줄 위(아래쪽을 집게로), 짝수 번째는 줄 아래(위쪽을 집게로). 이웃 사진은 `margin-left: -84px`로 겹친다.
- 사진 폭 `--w`는 화면 높이를 따른다: 중요도 1 `clamp(200px, 36vh - 20px, 240px)`, 2 `clamp(240px, 44vh - 22px, 290px)`, 3 `clamp(260px, 52vh - 72px, 340px)`. 줄 위아래 절반 안에 사진이 다 들어가야 한다.
- 가로 모드 캡션은 제목과 날짜만. 화면 높이 800px 이상일 때만 요약 2줄을 더한다. 태그는 상세 페이지에서만.
- 연도가 바뀌는 첫 사진에는 줄의 반대편에 종이 꼬리표(`.year-tag`)가 붙는다.
- 가로 모드 스타일은 컴포넌트 안에 `:global(html.is-horizontal) .클래스`로, 세로 스타일 아래에 둔다.

### 인화 사진
- 구성: 인화지 테두리 10px → `Photo`(3:2, 날짜 각인) → 캡션(제목, 날짜와 장소, 요약, 태그).
- 커버 사진이 없으면 `.backdrop`(그 시대 배경지를 찍은 빈 사진)이 들어간다. `Photo`에 `era`를 넘겨 배경지 색을 자기 시대 것으로 고정한다.
- 중요도: 1 지갑 사진(테두리 7px, 작은 제목), 2 보통, 3 나무 액자(`--frame` 10px) + 흰 매트 + 큰 제목. 크기와 액자로 구분하며 색만으로 구분하지 않는다.
- 사진 전체가 링크다(`.title a::after`). 사진 안에 다른 링크나 버튼을 넣지 않는다.
- 커버는 `astro:assets`의 `<Image>`(Photo.astro 안)로만 넣고 `coverAlt`를 채운다.

### 현상소 봉투 (시대 머리)
- 파란 인쇄 양식: 머리글 "밤팔이 사진관 현상·인화 / 봉투 NN", 칸 "이름 / 기간 / 매수", "메모" 아래 부제와 소개 글.
- 칸에 적힌 값(시대 이름, 기간, 매수, 부제)은 그 시대의 `--font-display`로 손으로 적은 듯 쓴다. 인쇄된 칸 이름은 본문 글꼴 + `--envelope-ink`.

## 시대 전환 동작

- JS가 있으면 `html.js-theme`가 붙고, 화면 중앙점이 들어 있는 시대 id가 `html[data-active-era]`에 들어간다. body의 배경지 조명이 그 색으로 0.8초에 걸쳐 바뀐다.
- 색 변수는 `@property`로 `<color>` 등록되어 있어야 보간된다. 등록을 지우면 전환이 끊긴다.
- 제목 글꼴은 보간되지 않으므로 `.era[data-era=…]`마다 항상 자기 `--font-display`를 갖는다 (`eraThemeCss`).
- JS가 없으면 각 `.era` 섹션이 자기 배경지 색을 갖고 구역별로 나뉜다. 이 동작을 깨지 않는다.
- 시대 섹션에 인라인 `style`로 색을 넣지 않는다. 예외는 `Photo`의 `--bg`(빈 사진 속 배경지)뿐이다.

## 접근성 (반드시 지킬 것)

- 대비: 배경지 위 `fg`, `muted`, `accent` 모두 4.5:1 이상. 인화지·봉투 위 글자는 고정 토큰으로 이미 통과한다.
- 날짜 각인은 장식이다(`aria-hidden`). 같은 날짜를 캡션의 `<time>`에 글자로 반드시 적는다.
- `prefers-reduced-motion: reduce`이면 가로 모드, 배경지 전환, 사진 똑바로 서기, 현상 애니메이션을 모두 끈다.
- 포커스는 사진 전체에 `--accent` 외곽선으로 보인다. 키보드 Tab으로 사진을 옮기면 가로 모드에서도 그 사진이 화면 가운데로 와야 한다.
- `.timeline-sticky`는 `overflow: clip`이어야 한다. `hidden`이면 포커스 이동 때 위치가 어긋난다.
- 타임라인 페이지에서는 CSS `scroll-behavior: smooth`를 켜지 않는다.
- 기울인 사진이 화면 밖으로 나가 가로 스크롤을 만들지 않게 감싸는 영역에 `overflow-x: clip`을 둔다.

## 하지 말 것

- 시대마다 레이아웃이나 사진 구조를 다르게 만들기. 바꾸는 것은 테마 토큰뿐이다.
- hex 색을 컴포넌트 CSS에 직접 쓰기. 예외: `--frame`(나무 액자) 같은 재료 색은 컴포넌트 안에서 변수로 선언한다.
- 사진관과 상관없는 장식(아이콘 세트, 그라데이션 띠, 이모지) 추가.
- 외부 UI·애니메이션 라이브러리 추가.
- 스크롤 핸들러에서 매번 레이아웃을 읽고 쓰기. `requestAnimationFrame`으로 묶는다(`requestUpdate` 참고).

## 변경 후 확인 체크리스트

1. `npm run check:contrast` 통과
2. `npm run build` 성공 (사건 날짜가 시대 기간을 벗어나면 여기서 실패한다)
3. `npm run dev` 후 브라우저에서:
   - 1440×860과 1000×640: 가로 스크롤로 처음부터 끝까지, 배경지 색이 부드럽게 바뀌는지, 줄 위아래 사진이 화면 밖으로 잘리지 않는지, 가로 스크롤바가 생기지 않는지
   - 375×812: 세로 건조 줄, 가로 넘침 없음
   - 상세 페이지에서 "앨범으로 돌아가기"를 누르면 그 사진이 화면 가운데에 오는지
   - Tab 키로 사진 이동
4. 가능하면 OS의 "동작 줄이기"를 켜고 세로 모드로 바뀌는지 본다.
